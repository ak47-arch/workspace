The legacy feed_analyser application is archived.

- [Software Factory](software-factory.md) - The software factory paradigm governing the workspace — five components (context engine, product/architecture, project management, assembly line, evaluation), the task lifecycle state machine with merge bundles, the PRD stable-home manifest lifecycle, typed-link disclosure trail with decision summaries, temporal metadata, the automated transition tooling with task-branch commits, and the headless GitHub Actions loop (implement → review → revise → sync).
- [Survival Infrastructure](survival-infrastructure.md) - Personal intelligence pipeline — captures freeform event narratives, extracts structured data via LLM, stores people/event nodes, and synthesizes wiki pages.
