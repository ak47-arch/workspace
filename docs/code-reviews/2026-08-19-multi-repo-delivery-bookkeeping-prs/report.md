## Findings
### Blocking (→ REQUEST_CHANGES)
- **B-1 (US2/US4, correctness) `bin/implementer-run.sh:419-441`** — `assert_delivery_invariant` runs at the end of `deliver_repo_set` with `BOOKKEEPING_PR` (implementer-run.sh:169) never assigned in the implementer flow. For Shape A (root not touched, ≥2 app repos) `has_root_code=false` AND `has_bk=false` → the "neither" branch fires → `return 1` → `fail_run`. A legitimate multi-app-repo task **always fails delivery**. The unit test passes only because it sets `BOOKKEEPING_PR=…` directly before calling the function. Fix: defer the Shape-A invariant assert until after the bookkeeping PR is raised (or assert only `has_root_code → no bookkeeping` at implementer time), or have factory-run re-assert after `finish_bookkeeping`.
- **B-2 (US8) `.github/workflows/factory.yml` + `bin/factory-run.sh:211-233`** — pickup gate is not wired. `pickup_gate()` returns immediately unless `FACTORY_REPOS` is set (only the test sets it); the workflow's "Run headless factory loop" step has no preceding `gh pr list --search` gate (grep: NONE). PRD decision explicitly requires the gate in the workflow alongside PRD-Final + task-prd-ready. Fix: add the gate step to factory.yml (and/or export `FACTORY_REPOS` for the live invocation).
- **B-3 (US1/2/4/7) `bin/factory-run.sh:199-209` (finish_bookkeeping) + `:200`** — bookkeeping PR creation is gated on `BK_MANIFEST`, which no live caller sets. implementer-run.sh writes the manifest to `$RUN_DIR/manifest.json` (default in `write_run_manifest`, implementer-run.sh:467); factory-run never links `BK_MANIFEST` to `$RUN_DIR/manifest.json`. So on a real run the Shape A bookkeeping PR is never raised and the manifest is never mirrored into a bookkeeping PR body. Fix: default `BK_MANIFEST="${BK_MANIFEST:-$RUN_DIR/manifest.json}"`.
- **B-4 (US9) `bin/factory-run.sh:346-385` + `bin/review-run.sh`** — the headless loop reviews and revises a single `PR_ARG`. `review-run.sh` gained only run-dir verdict writes (review-run.sh:799-820), no PR-set resolution (`<PR1> [<PR2>…]` per the PRD call-stack). Per-repo revise-only-rejected-repos and re-review over the whole set are not implemented. Fix: add PR-set handling to `review-run.sh` and loop the whole set in `headless_loop`.
- **B-5 (US7 mechanics) `bin/factory-run.sh:130`** — `raise_bookkeeping_pr` does `git clone --local "$WORKSPACE"` then `git push -u origin "$branch"`, but the clone's `origin` points at the **local** `$WORKSPACE`, not the GitHub remote (contrast with implementer-run.sh:774 which correctly does `remote set-url origin "$real_url"`). The branch never reaches GitHub, and the subsequent `gh pr create … || true` (factory-run.sh:164) silently swallows the failure → no bookkeeping PR, F3 fail-loud violated. Fix: reset the clone's origin to the GitHub URL before pushing, and surface the create failure.
